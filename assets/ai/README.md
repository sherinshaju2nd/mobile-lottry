# Kerala Lottery AI — Mobile Agent Asset Kit

Includes:
- 8 AI character state images
- 5 ambient background images
- mobile screen references
- SVG microphone/search/database/success/error icons
- agent-motion.json state machine
- AgentMotion.tsx React Native Reanimated motion base

States:
idle → listening → thinking → searching → processing → speaking → success
error can be entered from working states.

Note: character PNGs are cropped visual references from the generated concept sheet.
For production, replace them with transparent PNG/WebP or Lottie/Rive exports while
keeping the same filenames/state names.
